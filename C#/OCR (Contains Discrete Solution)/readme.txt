1. convert PDF file to directory of PNG's using PDF-To-PNG
2. install required app using Pre-Requires directory (read the readme file within this directory)
3. install .net 9 at least and compile and run PNG-To-TXT-Tesseract-MultiTrhead project
4. if output files are not ordered properly, run TXTCombiner app to get one ordered .txt file.
5. enjoy
